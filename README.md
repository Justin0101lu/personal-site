# personal-site

Static pages, served straight from the repo.

- `index.html` — personal landing page
- `direct-shipper/` — Direct Shipper, a clickable prototype of a freight-analysis tool for
  trucking carriers. Parses rate confirmations into a freight profile, then
  surfaces receivers, dormant brokers and lookalike facilities. No backend;
  all data is in-page fixtures. Not a live product.
